oTree Lab Launcher

GitHub

Make any working oTree project run in your lab with one click.

What it does

You have an oTree study that runs on your own machine. Getting it running across a room of lab PCs is the annoying part: a Postgres database has to be created and pointed at, the participant list has to be loaded, and an experiment room has to be defined so each seat connects to the right session. The Lab Launcher does all of that for you. Point it at any working oTree project, click once, and it wires up Postgres, participant lists and experiment rooms, then starts the server ready for the room to connect.

How it works

Everything that is specific to your lab lives in one file. A gitignored lab_info.json holds the settings the launcher needs — database credentials, the host address, which study is running — so nothing lab-specific is committed to the experiment repository, and the same project moves between labs by swapping that one file. Room layouts sit alongside it under maps/, one map per room describing which seats exist and how they are labelled.

The first time you run the launcher, a setup wizard fills all of this in for you. It walks through the questions once, writes lab_info.json and the room maps, and from then on launching is the single click.

Once the server is running, each lab PC opens its own per-seat link — one URL per desktop that drops that participant straight into their seat in the experiment room: 

http://HOST:8000/room/study?participant_label=SEAT

You place that link on each desktop once, with HOST, the study name and the seat's SEAT label filled in from the room map. After that the operator just clicks launch and the room is ready.

Open source

View on GitHub

The Lab Launcher is open source and free to use. It is built for Windows lab machines, the setup most computer labs actually run, so the setup wizard and per-seat links are geared to that environment.
